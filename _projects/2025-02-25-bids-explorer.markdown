# BIDS Explorer
<a href="https://sam54000.github.io/bids_explorer/bids_explorer.html">API Documentation</a>

## Project Overview
BIDS Explorer is a Python-based tool designed to make working with Brain Imaging Data Structure (BIDS) datasets more intuitive and efficient. It provides researchers with powerful search capabilities and visualization tools to better understand their neuroimaging data organization.

## Features
- Advanced search functionality for BIDS datasets
- Interactive visualization of dataset structure
- Metadata validation and quality checks
- Support for multiple neuroimaging modalities
- Command-line and GUI interfaces

## Technical Details
The tool is built using Python with a focus on:
- BIDS specification compliance
- Efficient dataset traversal
- User-friendly interface design
- Extensible architecture for future enhancements
